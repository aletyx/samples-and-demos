# Requests

The requests that shaped Life Hub, oldest first, each with what changed.
The feature files hold the current specification; see the
[index](README.md).

## 2026-10-23

1. **Build a new demo with the same structure as Contact Hub and Mortgage
   Hub: Conway's Game of Life, with the rules as an aityx decision model;
   an infinite board, a random start button, a side panel with the
   requests and responses, and an acceleration control.** Added
   `LifeHub/`: the Flutter app (`lifehub_app`, web, Android, iOS and
   Linux) with the [board](board.md) on a canvas (drag, zoom, tap to draw,
   **Random start**, **Clear**, **Play**, **Step**, **Acceleration** from
   ½ to 8 generations a second or as fast as aityx answers) and the
   [calls panel](calls-panel.md) (every call, what it decided, the request
   and the response as readable JSON with the key parts labeled); a Dart
   API (`lifehub_api`) with `POST /api/step` and `/api/health` that holds
   the aityx key; the Life model (`models/life.json`): Conway's rules as
   a decision table with a why on every row, applied by one aityx call per
   [generation](generation.md) to every distinct situation on the board
   (at most 18), the app counting situations and applying the answer to
   its cells; devbox, process-compose and the health monitor, the
   Makefile, Docker Compose, and the dev container in
   `.devcontainer/LifeHub/`, as Contact Hub has them (see
   [Development environment](dev-environment.md)). Ports 8900 and 8901,
   so it runs alongside the others. The [theme](theme.md) is the aityx
   palette; the [icon](app-icon.md) a glider. The key was copied into
   `LifeHub/.env` from Contact Hub's (git-ignored), to test against the
   live API: `scripts/model-test.sh` runs all 18 situations on aityx.
2. **Also detect patterns, if possible, and notify of them, using aityx;
   check Wikipedia's Game of Life page for the common patterns.** The
   app now also sends every cluster of live cells with its canonical
   shape, and the model's [pattern catalogue](patterns.md), generated by
   `tool/catalogue.dart` from the patterns Wikipedia lists (five still
   lifes, five oscillators, four spaceships, three methuselahs; 37 rows,
   one per phase and size), names each one in the same call, with a
   second table that says what kind it is and describes it. Recognized
   patterns are outlined and named on the board; when a generation has
   more of a pattern than the last, a notice appears over the board and
   in **Patterns noticed** at the top of the panel, with what the pattern
   is. `scripts/model-test.sh` also sends every catalogue shape to aityx.
3. **Let rules be enabled and disabled, Conway's enabled by default, and
   add a couple more rules to make the game more interesting, disabled by
   default.** The request's state now carries `rules`, a switch per rule,
   and each rule's rows in the model's fate table are gated by its
   switch: Conway's (on at the start), HighLife's birth with six
   neighbours (B6, replicators) and Life without death (cells never die),
   both off; a live cell no enabled rule keeps alive dies. **Rules (1 of
   3)** in the controls bar opens a dialog of checkboxes with each rule's
   summary; a change applies from the next generation. See
   [Rules](rules.md).
